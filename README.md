📱 Mi Card Flutter

A simple Flutter business card app that displays a personal profile with contact information.

✨ Features
Profile picture using CircleAvatar
Name and short bio
Phone contact card 📞
Email contact card 📧
Clean Material Design UI using Card and ListTile
Responsive centered layout
🧠 What I learned

This project helped me understand:

Flutter widgets (Scaffold, Column, Row)
Layout structure (Center, SizedBox, Divider)
Using Card and ListTile
Styling text with TextStyle
Using CircleAvatar with network images
Basic UI design principles in Flutter
